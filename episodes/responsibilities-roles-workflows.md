::::::::::::::::::::::::::::::::::::: objectives

After following this episode, learners will be able to:

- Recall the resolution strategies that Git implements (be knowledgeable) 
- Recall the commands to resolve conflicts in Git (be knowledgeable)
- Recognise how free-style committing can make the life of others miserable (be responsibile)
- Write commit messages intended for people wih whom you do not have set a policy (be informative)
- Define what kind of order a policy is [__not SMART__] 
- Plan together a policy for deciding what goes into the main branch (be selective) (...and what the main branch is for...)
- Plan together a policy for dividing the workload between the team members according to similar processes or similar topics (be involved, assign ownership, workflow)
- Recognise a [definite] number of classical templates for policies (workflow)
